# WebDevPro Ultra Max 5 — Master Website Template

Reusable production-ready WebDevPro master template based on the approved Granite Installations website design.

## Included
React 18 + TypeScript + Vite + Tailwind, multi-page routing, animated hero/sections, gallery, FAQ, testimonials, premium Contact page with dropdown + map, PWA support, mobile footer navigation, and an interactive WhatsApp lead assistant that collects visitor details before opening WhatsApp.

## Rebranding
Read `MASTER-TEMPLATE-5-GUIDE.md` before each client rebrand. Preserve the layout/features and replace client branding, content, images, contact details, map and theme colors.

## Development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
```

## Vercel
Upload the repository contents to GitHub, import into Vercel, select Vite, build with `npm run build`, output `dist`. `vercel.json` is already included for direct-route support.
